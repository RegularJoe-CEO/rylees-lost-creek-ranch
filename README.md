# Rylee's Lost Creek Ranch

Grade 4 math game for Rylee. Ranch jobs: fishing, range, wildlife trail, creek crossing.

The Module 2 measurement trail follows the published Grade 4 lesson order. Choose Rylee's current school lesson on the trail, review earlier place-value chapters anytime, or try later metric lessons and a multiplication warm-up. All questions are original supplemental practice; see [curriculum mapping](docs/CURRICULUM.md) for coverage and limits.

## Play on iPhone or iPad
